# Algorithm Visualizer

An interactive web-based platform that visualizes **Sorting** and 
**Machine Learning** algorithms step by step, built with Python and Streamlit.



##  Features
- **Sorting Algorithms** — Bubble Sort, Merge Sort, Quick Sort
-  **ML Algorithms** — Linear Regression, KMeans, KNN, 
  Decision Tree, Random Forest, Logistic Regression
-  **Agricultural Dataset** — Real crop yield, rainfall, 
  temperature and pesticide data
-  **Step-by-step animation** with Play, Pause and Reset controls
-  **Configurable** — adjust speed, array size and hyperparameters
-  **Professional dark UI** — black and purple theme

##  Tech Stack
| Tool | Purpose |
|------|---------|
| Python 3.10+ | Core language |
| Streamlit | Web UI framework |
| Scikit-learn | ML algorithms |
| Plotly | Interactive charts |
| Pandas & NumPy | Data processing |
